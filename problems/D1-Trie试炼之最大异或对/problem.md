# D1 Trie试炼之最大异或对

- 比赛：2026年蓝桥杯集训队之高级数据结构
- 题型：OI
- 难度：High
- 语言：C, C++, Python3

## 题目描述

<p>在给定的 N 个整数 A1, A2, …, AN 中选出两个进行 xor（异或）运算，得到的结果最大是多少？</p><p style="color:#888;font-size:smaller;">来源：《算法竞赛进阶指南》（李煜东著）</p>

## 输入描述

<p>第一行一个整数 N。第二行 N 个整数 A1∼AN。</p>

## 输出描述

<p>一个整数，表示答案。</p>

## 样例

### 样例 1

#### 输入

```text
10
181262 369842 1036879 546331 868986 496157 646816 459571 215643 448018
```

#### 输出

```text
1033222
```
