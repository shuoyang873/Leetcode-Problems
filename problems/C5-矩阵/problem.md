# C5 矩阵

- 比赛：2026年蓝桥杯集训队之高级数据结构
- 题型：ACM
- 难度：High
- 语言：C, C++, Java, Python3

## 题目描述

<p>给定一个 M 行 N 列的 01 矩阵（只包含数字 0 或 1 的矩阵），以及若干个小矩阵。对于每个询问给出的 A 行 B 列小矩阵，判断它是否在大矩阵中出现过（即大矩阵中是否存在一个 A×B 的子矩阵与它完全相同）。</p><p style="color:#888;font-size:smaller;">来源：《算法竞赛进阶指南》（李煜东著）</p>

## 输入描述

<p>第一行包含四个整数 M, N, A, B，其中 M 和 N 是大矩阵的行数和列数，A 和 B 是小矩阵的行数和列数。</p><p>接下来 M 行，每行 N 个字符（0 或 1），表示大矩阵。</p><p>接下来一行包含一个整数 Q，表示询问个数。</p><p>接下来 Q 个询问，每个询问包含 A 行，每行 B 个字符（0 或 1），表示一个小矩阵。</p>

## 输出描述

<p>输出 Q 行，每行一个整数：若该小矩阵在大矩阵中出现过输出 1，否则输出 0。</p>

## 样例

### 样例 1

#### 输入

```text
3 3 2 2
111
000
111
2
11
00
10
10
```

#### 输出

```text
1
0
```
