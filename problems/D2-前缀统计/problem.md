# D2 前缀统计

- 比赛：2026年蓝桥杯集训队之高级数据结构
- 题型：ACM
- 难度：High
- 语言：C, C++, Java, Python3

## 题目描述

<p>给定 N 个字符串 S1,S2…SN，接下来进行 M 次询问，每次询问给定一个字符串 T，求 S1～SN 中有多少个字符串是 T 的前缀。输入字符串的总长度不超过 10^6，仅包含小写字母。</p><p style="color:#888;font-size:smaller;">来源：《算法竞赛进阶指南》（李煜东著）</p>

## 输入描述

<p>第一行两个整数 N, M。<br />接下来 N 行每行一个字符串 Si。<br />接下来 M 行每行一个字符串表示询问。</p>

## 输出描述

<p>对于每个询问，输出一个整数表示答案。</p>

## 样例

### 样例 1

#### 输入

```text
3 2
ab
bc
abc
abc
efg
```

#### 输出

```text
2
0
```
